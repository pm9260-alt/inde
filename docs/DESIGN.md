# デザインの決めごと

すべての値は `src/design/tokens.ts` にあります。画面側でリテラルの色や
サイズを書くことはしません。ここではその背景を記します。

---

## 核にある考え

**冷たい空 / 温かい物語。**

星を探しているあいだ、画面には冷たい色しかありません。夜そのものの色と、
青灰色の星座線だけです。星座を選んで物語が始まった瞬間に、はじめて色が
温度を持ちます。この温度の変化そのものが「物語が灯る」という合図です。

色を増やして華やかにする方向は取っていません。色は 2 系統だけです。

---

## 色

### アクセント色の出どころ

橙は雰囲気で選んだ色ではありません。

オリオン座のベテルギウスと、さそり座のアンタレス。どちらも赤色超巨星で、
MVP の中心にある二つの神話の主役でもあります（互いを追い、決して同時に
空へ出ない二つの星）。この橙は、生成した星表にあるベテルギウスの
B-V 色指数から実際に導いた色 `[1, 0.541, 0.222]` を、暗所表示用に整えた
ものです（`src/data/stars.generated.ts` の `hr:2061`）。

### 暗所での配慮

- **純黒（#000）を使わない。** 有機ELの黒つぶれとカメラノイズの境目が硬く
  なり、夜空の連続性が切れます。最暗色は `#05070B`。
- **純白（#FFF）を使わない。** 夜間の白は眩しく、残像が残ります。本文は紙の
  ようにわずかに暖かいオフホワイト `#EFE8DC`。古い星図の紙の色でもあります。
- **青を主要面から抜く。** 短波長の光は暗順応を最も壊します。

### 階調

最暗背景 `#05070B` に対するコントラスト比：

| 用途 | 色 | 比 |
|---|---|---|
| 本文・見出し | `#EFE8DC` | 16.6 |
| 補助情報 | `#A9A497` | 8.1 |
| 注記・単位 | `#716E67` | 4.0 |
| アクセント | `#F2A85E` | 10.1 |

アクセントと本文は輝度が近いので、色だけで意味を区別させていません。
選択状態は必ず位置か太さでも示しています。

## 書体

2 書体だけ。どちらも大平善道氏による Zen ファミリーで、骨格が共通している
ため、明朝とゴシックを混ぜても字面が揃います。どちらも SIL OFL 1.1。

| | 書体 | 役割 |
|---|---|---|
| 物語の声 | **Zen Old Mincho** | 神話の本文、星座名。仮名の抑揚が強く、長文を読ませる格がある。ラテン部も本格的なセリフなので和欧混植が破綻しない。 |
| 装置の声 | **Zen Kaku Gothic New** | UI、数値、ラベル。小さい字面でも暗所で潰れにくい。 |

和文の行間は欧文より広く要ります。明朝の長文は 1.9、ゴシックの UI 文は
1.5〜1.7。暗所では字が滲むため、小さいサイズほど字間をわずかに開けています。

## 画面の作り

### スカイビューでは、既定の状態で文字が 1 つも出ない

夜空を邪魔しないことが最優先です。出るのは次の場合だけです。

- 端末をある星座へ向けている → その名前が下に浮かぶ
- 利用者が何かをしないと表示がずれ続ける → 上部に一行

「囲い」を作りません。名前の上に 28px の短い線を 1 本引くだけで、面は使い
ません。文字の可読性は、面で覆うのではなく、文字自身のごく淡い影で確保
しています。カメラ映像を隠さないためです。

### グラデーションを使わない

読みやすさのために暗幕を敷く場面はありますが、そこでも単色の半透明を使い、
グラデーションは引いていません。神話シートの背景も単色です。

### 角丸を控える

半径は 2 / 6 / 10、そして下から出るシートの上端だけ 18。それ以上は使いません。

### アイコンを増やさない

このアプリのアイコンは 0 個です。「調整」「閉じる」「つづき」はすべて文字です。
状態を示す小さな点だけが、唯一の非文字要素です。

### 動きの速さ

| 用途 | 時間 |
|---|---|
| 押した瞬間の反応 | 110ms |
| 表示状態の切り替え | 200ms |
| シートの出入り | 380ms |
| 星座線が引かれる演出 | 900ms |
| 星の明滅・情景の転換 | 1600ms |

UI の出入りは速く、星の演出だけがゆっくり動きます。UI は待たせるもの
ではなく、星は見せるものだからです。

## 神話の見せ方

長文を一度に出しません。場面をひとつずつ送ります。

シートは画面の下 6 割まで。上 4 割には夜空が残ります。読んでいるあいだも、
いま語られている星が空のどこにあるのかが見えていることが前提です。

場面が変わると、空の側で光る星が変わります。オリオン座の最後の場面は
さそり座を指しているので、そこで線の色がさそり座へ移ります。物語が空を
横切っていきます。これが 30〜60 秒の AR ストーリー体験へ広げるときの骨組み
です（`src/data/myths/types.ts` の `focus` と `figure`）。

どこまで読んだかは、数字ではなく場面の数だけ並ぶ短い線で示します。
「あと何ページ」を意識させず、それでも終わりがあることは伝わります。

## アプリ名とアイコン

**星めぐり。** 宮沢賢治「星めぐりの歌」から。あの歌に出てくるのは、さそり、
鷲（夏の大三角のアルタイル）、オリオン ── MVP の星座そのものです。

アイコンはオリオン座の三つ星。このアプリを最初に開いた人が最初に探す形で、
5 つの星座のうち最も見つけやすく、最も知られた並びでもあります。斜めに三つ
並ぶだけの形は、40 ピクセルまで縮んでも読めます。

名前もアイコンも `app.json` と `scripts/build-icons.py` を直せば変えられます。
